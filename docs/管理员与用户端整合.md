# SpeakMate 用户端与管理员系统整合

用户端源码：`app/frontend`；管理员前端源码：`app/admin`；共用后端：`app/backend`。
桌面提供的管理员后端路由已存在于主项目，已核对其余路由一致；未另建第二套服务或数据库。

## 构建与启动

在仓库根目录执行：

```powershell
.\build-web.ps1 -Install
python run_backend.py
```

用户端：<http://127.0.0.1:8000/>；管理员端：<http://127.0.0.1:8000/admin-ui/>。
Python 依赖仍由根目录 `requirements.txt` 管理。管理员端构建输出 `app/admin-dist`，用户端输出 `app/frontend/dist`。
后端启动时检测这两个构建目录。首次构建后需重启后端。

创建管理员（将示例手机号、密码替换为自己的值）：

```powershell
python tools/create_admin.py 你的手机号 你的密码 --super
```

该命令对已有账号会重置密码并提升权限，请只对需要管理权限的账号执行。
管理端与用户端共享 `.env` 中的 `COACH_DB_PATH`，未配置时共用根目录 `data/coach.sqlite`。
管理员依旧使用手机号登录，角色由后端检查，不会自动授权普通用户。

## 开发

启动后端：`python run_backend.py`。
用户端在 `app/frontend` 执行 `npm run dev`，访问 5173 端口；管理员前端在 `app/admin` 执行 `npm run dev`，访问 <http://127.0.0.1:5174/admin-ui/>。
两个 Vite 服务均将 `/api` 代理到 8000 端口。

## 本次功能

- 自由对话“知识库”入口位于“双语”左侧，桌面及手机均提供。点击展示待开放提示；按需求暂不上传文件或实现 RAG。
- “我的”支持用户名（1–24 个字符）和 6 个默认头像，正式账号同步到 `users` 表，管理员“用户管理”可显示并按用户名搜索。游客资料跟随当前游客身份保存。
- 场景卡片点星收藏，“我的 → 收藏的场景”可开始练习或取消。新收藏按登录身份保存于 `account_favorites`，支持没有学习档案的用户，重复收藏不会重复写入。
- 管理员“账号场景收藏”支持查询、新增、修改、删除，支持手机号/游客 ID 和场景 ID 搜索。概览统计使用此表。
- 旧 `favorites` 数据没有可靠的账号归属，保留在“历史档案收藏”供管理员查看，没有自动分配给任何账号。
- 语音输入后的 AI 消息显示可点击播放的语音条，下方显示较小的英文文字。每条语音消息的“翻译中文 / 收起中文”独立控制翻译，默认不翻译语音消息。语音/文字模式写入数据库，重新进入会话可恢复；原始录音不上传保存，刷新后用户语音条可使用文本合成重播。无原始录音时显示的时长为估算值。
- 首页右上角“设置 → 退出登录”清理令牌、停止音频并返回登录页，同时清理上个账号的场景导航缓存。
