# 数据文件 + 清洗说明

本目录提供 SpeakMate 项目中**全部内置业务数据**的结构化导出(JSON + CSV 双格式)及清洗说明。

## 一、数据文件清单

| 文件 | 内容 | 条数 |
|------|------|------|
| `scenarios.json` | 6 个口语陪练场景的完整定义(背景、NPC/学员角色、目标、5 档难度) | 6 个场景 |
| `scenarios_flat.csv` | 场景数据平铺表(每个难度档一行,共 6×5=30 行),便于 Excel / 数据库导入 | 30 行 |
| `grammar_rules.json` | 24 条确定性语法纠错规则(规则 ID、错误类型、中文说明、出处键) | 24 条 |
| `grammar_rules.csv` | 同上,CSV 格式 | 24 行 |
| `grammar_knowledge_rag.json` | RAG 语法知识库 24 条(分级 levels、英文讲解、来源与出处 URL) | 24 条 |
| `grammar_knowledge_rag.csv` | 同上,CSV 格式 | 24 行 |

> 这些数据原本以 Python 元组内嵌在源码中(`app/backend/app/scenarios.py`、`grammar_rules.py`、`grammar_rag.py`)。本目录通过导出脚本将其抽离为开放数据格式,便于评审核对、统计分析或迁移到数据库 / 向量库。

## 二、数据来源

| 数据集 | 来源文件 | 原始形态 |
|--------|----------|----------|
| 场景库 | `app/backend/app/scenarios.py` → `SCENARIOS` | `tuple[Scenario, ...]`,手工精心设计 |
| 语法规则 | `app/backend/app/grammar_rules.py` → `RULES` | `tuple[GrammarRule, ...]`,确定性规则 |
| RAG 知识库 | `app/backend/app/grammar_rag.py` → `GRAMMAR_KNOWLEDGE` | `tuple[dict, ...]`,手工编写 + 引用外部权威语法资料(British Council 等) |

所有数据均为**人工策划(curated)**的确定性数据,由开发者在项目演进过程中逐条编写,无网络爬取、无外部导入。

## 三、清洗过程

原始数据为 Python 对象,导出时做了以下清洗与规范化:

1. **结构标准化**:将 dataclass / dict 对象统一转为 JSON 对象;嵌套的 `DifficultyBand` 元组转为 `difficulty_bands` 数组。
2. **枚举展开**:`target_functions`(目标语言功能)与 `levels`(适用难度等级)原本是元组,导出为数组(JSON)或用 `;` 分隔(CSV)。
3. **编码处理**:所有文件统一 UTF-8;CSV 采用 **UTF-8 with BOM**(`utf-8-sig`),保证在 Windows Excel 中直接打开中文不乱码。
4. **字段规整**:统一命名风格为 `snake_case`;去除源码中的注释与无关字段。
5. **数据校验**:导出后核对条数(场景 6、规则 24、知识库 24),并抽样检查 ID 一致性 —— `grammar_rules` 与 `grammar_knowledge_rag` 的 `rule_id` 一一对应(24/24),确保纠错规则与 RAG 知识库可关联检索。

## 四、关键字段说明

### scenarios.json / scenarios_flat.csv

- `id`:场景唯一标识,如 `airport-check-in`
- `category`:场景分类(出行 / 餐饮 / 求职 / 医疗 / 购物)
- `difficulty_bands[].level`:难度档 A1–C1(CEFR 五档)
- `vocabulary_range`:该档词汇量区间(如 `80-150 high-frequency travel words`)
- `sentence_complexity`:该档句型复杂度描述
- `target_functions`:该档要求学员掌握的语言功能(如 `greet`、`ask for help`)

### grammar_rules.json / grammar_rules.csv

- `rule_id`:规则唯一标识,与 RAG 知识库的 `rule_id` 对应
- `error_type`:错误类型(中文,如 `主谓一致`)
- `title` / `explanation_zh`:规则标题与中文讲解(用于前端纠错卡片展示)
- `source_key`:规则出处键,用于 RAG 检索定位

### grammar_knowledge_rag.json / grammar_knowledge_rag.csv

- `levels`:该知识条目适用的难度等级(如 `["A1","A2","B1"]`),检索时按学员水平过滤
- `content`:英文知识点讲解
- `source` / `source_url`:知识来源与出处链接(British Council 等公开语法资料)

## 五、数据如何被使用

- **场景库**:前端场景选择页展示 6 个场景;进入练习时按学员水平选中对应难度档,生成对话开场与背景设定。
- **语法规则**:纠错流水线第一阶段 —— 规则引擎先对学员句子做确定性匹配(24 条规则),命中后生成纠错卡片;未命中的交由 LLM 深度分析。
- **RAG 知识库**:纠错时按学员等级 + 规则 ID 检索对应知识条目,附在纠错卡片的「为什么」部分并给出规则出处,实现可解释纠错。
